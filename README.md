# Clawd Agents

**一群住在你 Windows 桌面上的橙色像素小人。**

它们不是屏保，也不是会动的壁纸——它们有自己的想法：自由乱跑、速度时快时慢、偶尔钻进打开的窗口躲起来、再从窗口上沿探出半个脑袋偷看，你鼠标一靠近就朝反方向逃。

整个程序就是一个透明无边框的置顶窗口，用色键把背景抠掉，桌面上只看得到小人本身。透明区域连点击一起穿透，只有小人的身体会挡住鼠标，所以它不会妨碍你做任何事。

## 快速开始

**方式一：下载即用**

到 [Releases](https://github.com/bietou123/clawd-agents/releases) 下载最新的 `ClawdAgents.exe`，双击运行。首次运行会在 exe 同目录生成 `config.json`。

**方式二：从源码运行**

需要 Python 3.10+（`tkinter` 是标准库自带，Windows 官方安装包默认包含），不需要装任何第三方包：

```bash
git clone https://github.com/bietou123/clawd-agents.git
cd clawd-agents
python clawd_agents.py
```

想让它开机自动出现：右键 → 设置 → 勾选「开机自启」，会写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`。

## 操作

| 操作 | 作用 |
| --- | --- |
| 左键点小人 | 把它绑定的窗口提到前台 |
| 右键任意位置 | 弹出菜单：设置 / 退出 |
| 设置面板 | 调完立刻生效，自动写入 `config.json` |

点击绑定规则：`config.json` 里的 `targets` 可以让「第 N 个小人」固定去管某个窗口，例如：

```json
"targets": ["Visual Studio Code", "Microsoft Edge", "WeChat"]
```

按标题关键字（不区分大小写）匹配。留空或者匹配不上时，退化为按窗口 Z 序取第 N 个——也就是"点第几个小人，就把第几层窗口翻上来"。

## 四种运动模式

### `hide` — 捉迷藏（默认）

最热闹的一个模式，行为是一套小状态机：

- **乱跑**：每次随机挑一个空位走过去，速度在 30–58 px/s 之间浮动，20% 的概率冲刺（1.9 倍速）、30% 的概率慢悠悠晃（0.5 倍速），到了就原地歇 0.3–2 秒
- **躲窗口**：身体一碰到窗口矩形就立刻隐身，至少藏 0.4–1.2 秒；隐身期间走得快一点，好从窗口另一边钻出来
- **探头**：藏好之后有一定概率趴到窗口上沿，只露出上半身（下半身按窗口顶边裁掉），东张西望 0.9–1.8 秒。同一时间只允许一个小人探头，每次探完冷却 3.5–7 秒
- **怕鼠标**：鼠标进入 3.2 个身位以内就朝反方向冲刺逃跑；探头时被鼠标摸到，会直接跳下来跑掉

判定用的是**整个身体**和窗口的重叠关系，不是中心点——否则小人在窗口边界上来回踱两像素，就会一帧隐一帧现，看起来像在闪。

### `right` — 贴边列队

所有小人排成右侧一列，各自按不同相位左右轻晃。这个模式窗口只有约 4 个身位宽，CPU 占用最低。

### `orbit` — 绕屏幕边缘跑

小人等分在屏幕四条边上，整体沿周长循环移动，像一队绕着屏幕巡逻的蚂蚁。

### `area` — 指定区域游走

在 `area` 指定的矩形里按李萨如曲线各自游走。窗口会自动缩到该区域的大小，所以同样比全屏模式省资源。

## 配置

首次运行会在程序同目录生成 `config.json`（也可以复制 `config.example.json` 改名）。设置面板里的改动会直接写回这个文件。

```json
{
  "mode": "hide",
  "count": 7,
  "size": 44,
  "speed": 1.0,
  "fps": 60,
  "area": [0.72, 0.08, 0.24, 0.84],
  "targets": []
}
```

| 字段 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| `mode` | `hide` | `hide` / `right` / `orbit` / `area` | 运动模式 |
| `count` | `7` | 1–12 | 小人数量 |
| `size` | `44` | 24–64 | 小人尺寸（逻辑像素） |
| `speed` | `1.0` | 0.2–3.0 | 速度倍率，影响移动和步频 |
| `fps` | `60` | 10–60 | 目标帧率；机器吃力就降到 30 |
| `area` | `[0.72, 0.08, 0.24, 0.84]` | 0–1 | `area` 模式的活动区域，按屏幕宽高比例 `[x, y, w, h]` |
| `targets` | `[]` | — | 点击第 N 个小人时前置的窗口标题关键字 |

配置写坏了也不要紧：读不出来的字段会回落到默认值。

## 工作原理

**透明窗口。** `root.overrideredirect(True)` 去掉标题栏和边框，`-topmost` 置顶，`-transparentcolor '#ff00ff'` 指定一个没人会用的品红色做色键，`Canvas` 背景也刷成同一个颜色。Windows 把整块品红像素当透明处理，并且这些像素对鼠标也是穿透的。

**像素小人。** 每个小人由若干矩形图元拼成：身体、两只眼睛、两条手臂、四条腿，全部用 `create_polygon` 绘制（多边形而不是 `create_rectangle`，因为翻跟头时要绕自身中心把每个顶点转过去）。

图元做过一次合并优化：四条腿颜色相同、顶边齐平，就合并成一个"梳齿多边形"——沿公共顶边把四根齿串起来，齿间连线高度为零，不会多填出一块；两只眼睛同理。每个小人的图元数从 9 个降到 5 个，而画布图元数量本身是重画成本的主要来源，详见下一节。

**遮挡检测。** `EnumWindows` 枚举可见顶层窗口（自上而下就是 Z 序），再用 `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)` 取不含阴影的真实边框，过滤掉工具窗口、透明窗口、太小的窗口和屏幕外的窗口。命中第一个窗口就只认它——否则小人会趴在被别的窗口挡住的那条边上，看起来像趴在窗口里面。

**帧调度。** 用绝对时间轴排下一帧（`next_ms += 1000 / fps`），而不是 `after(round(1000 / fps))`。后者每次取整误差都会累积，60 FPS 会慢慢漂成 56。启动时 `winmm.timeBeginPeriod(1)` 把系统定时器粒度从 15.6ms 提到 1ms，不然 30 FPS 会被压到 21。

**脏渲染。** 每帧算出的坐标会先取整比较，落在同一个整数像素上就跳过这次 `coords` 调用——小人走路每帧只挪半个像素的时候，这一下能省掉大量无谓的 GDI 重画和整层窗口合成。填充色、可见状态也一样做缓存，状态没变就不碰。

**窗口随模式伸缩。** 全屏透明窗口的合成开销和面积成正比，所以只有 `hide` 和 `orbit` 用全屏，`right` 只开一条 4 个身位宽的竖条，`area` 只开目标区域那么大。

## 性能

以下都是在 1920×1080 / 7 个小人 / 60 FPS 下实测的进程 CPU（Python 侧 tick 本身只占 0.35ms/帧，剩下的都是 Tk 和 Windows 合成的开销）：

| 场景 | CPU / 10 秒 | 迟帧（>25ms，共 600 帧） |
| --- | --- | --- |
| 7 个小人全部全速移动（最坏情况） | 2.62–2.86s | 11–15 |
| 正常捉迷藏游走 | 0.72–1.72s | 5–8 |
| 全部静止不重画 | ≈0.17s | — |

几个反直觉的实测结论，供后来者省点时间：

- **成本是"重画驱动"的**，不是"帧率驱动"的：什么都不动的时候几乎没有开销，一旦每个小人每帧都在动，CPU 直接翻几倍
- **图元数量大致线性地加钱**：同样大小的一块区域，用 14 个小图元移动的开销约是 1 个大图元的 1.8 倍。所以合并图元是划算的
- **一个窗口画所有小人，比每个小人一个透明窗口便宜得多**：后者 CPU 约 4 倍，因为每帧移动多个顶层窗口远比移动画布图元贵
- **调高进程优先级没用**：实测 HIGH_PRIORITY_CLASS 没有任何改善
- 空转的 Tk `after` 循环帧间隔地板就在 16.9ms 左右，剩下的长帧来自系统 / DWM，代码层面消不掉

## 常见问题

**看不到小人？**
先看看桌面上空白的地方——捉迷藏模式下它们大部分时间躲在窗口后面。右键 → 设置里把模式换成 `right`，它们会立刻跑到屏幕右边排队。另外 `count` 或 `size` 调得太小也会不太容易发现。

**exe 被杀毒软件拦了？**
PyInstaller 打包的未签名 exe 偶尔会被误报。不放心的话直接从源码跑，或者自己按下面的步骤重新打包。

**笔记本风扇转起来了？**
把 `fps` 降到 30，或者切到 `right` / `area` 模式（窗口面积小很多）。另外 `size` 和 `count` 也会影响开销。

**小人在某些窗口上不探头？**
贴着屏幕最上沿的窗口不会探头——头会探到屏幕外面去。这类窗口被当作"不可躲藏"，小人会直接穿过去。

**点小人没反应？**
窗口标题关键字没匹配上时会退化成按 Z 序取第 N 个窗口，这时点第一个小人可能只是把最上面那层再提一次。填好 `targets` 就准了。

**改了配置没生效？**
运行中的程序以内存里的配置为准；直接改 `config.json` 后需要重启程序，从设置面板改则是立刻生效的。

## 打包成 exe

```bash
pip install pyinstaller
python -m PyInstaller --noconfirm ClawdAgents.spec
```

产物在 `dist/ClawdAgents.exe`，单文件、无控制台窗口。不写 spec 也行：

```bash
pyinstaller --onefile --noconsole --name ClawdAgents clawd_agents.py
```

## 项目结构

```
clawd-agents/
├── clawd_agents.py        # 全部逻辑：窗口、绘制、动作、运动模式、设置面板
├── ClawdAgents.spec       # PyInstaller 打包配置
├── config.example.json    # 配置示例
├── index.html             # 同一套造型的网页版预览
├── docs/states.png        # 20 种动作总览图
├── LICENSE                # MIT
└── README.md
```

`clawd_agents.py` 主要分成三块：

- `PARTS` / `compute_pose()`：把 20 种动作翻译成一组身体参数（上下颠多少、哪只手抬多高、转多少度、要不要道具）
- `Agent`：一个小人的全部状态，负责把参数画成画布图元，带脏渲染缓存
- `App`：窗口、Win32 调用、运动模式（`roam()` / `position()`）、设置面板、帧循环

## 已知限制

- 只支持 Windows：色键透明、窗口枚举、开机自启动都依赖 Win32 API
- 「躲到窗口后面」是视觉模拟：置顶窗口没法真的排到别的窗口下面，命中窗口时直接把小人隐藏，再从边缘冒出来
- 覆盖的是主显示器，多屏还没有做
